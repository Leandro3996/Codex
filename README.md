# Codex

Chatgpt codex prueba

## Desarrollo

1. Instala dependencias:
   ```bash
   pip install -r requirements.txt
   ```
2. Ejecuta las migraciones iniciales:
   ```bash
   python codex_project/manage.py migrate
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   python codex_project/manage.py runserver
   ```
